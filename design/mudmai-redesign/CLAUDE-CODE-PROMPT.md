```
บริบท: อ่าน HANDOFF.md ก่อน โปรเจกต์นี้กำลังรีแบรนด์จาก "Journey Resolution" เป็น
"หมุดหมาย" (อังกฤษ: "Mudmai") ผมมีมอคอัพจาก Claude Design แนบมาให้ที่ [วางลิงก์ design canvas
ตรงนี้] เลือกใช้แนวทางตราสัญลักษณ์ A "เข็มทิศหมุด" (วงแหวน 6 จุดสีเดิมของ 6 เสาหลัก + ปลายแหลม
แบบหมุดปักแผนที่) เป็นมาร์กหลัก

งานที่ต้องทำ เรียงตามลำดับ:

1. เปลี่ยนชื่อแบรนด์ทุกจุดที่ hardcode คำว่า "Journey Resolution":
   - src/components/icons.tsx → BrandLockup component: เปลี่ยนข้อความ "Journey Resolution"
     เป็น "Mudmai" (locale th) / "Mudmai" (locale en) — ต้องรองรับสองภาษาแบบ dynamic ตาม
     locale ปัจจุบัน ไม่ hardcode ภาษาเดียว เช็คว่ามีระบบ locale string ที่ไหนอยู่แล้วไหม
     (next-intl) แล้วเพิ่ม key ใหม่ถ้ายังไม่มี แทนที่จะ hardcode ในไฟล์ component
   - src/app/layout.tsx และ src/app/[locale]/layout.tsx → metadata title/description
   - package.json → "name" (ถ้าต้องการให้ตรงกับแบรนด์ใหม่ด้วย ถามก่อนเปลี่ยนเพราะกระทบ
     deployment/domain)
   - README.md, HANDOFF.md → หัวเรื่องและการอ้างอิงชื่อโปรเจกต์ (ไม่ต้องรื้อเนื้อหาอื่น)

2. เปลี่ยนตราสัญลักษณ์ (icons.tsx):
   แทนที่ AppMark เดิม (ส่วนโค้งสีรุ้ง 6 จุด) ด้วยมาร์กแนวทาง A จากดีไซน์แคนวาส: วงแหวน 6 จุด
   สีเสาหลักเดิม (career/personal/finance/relationships/mental/physical — ใช้ hex เดิมจาก
   lib/pillars.ts ห้ามเปลี่ยนสี) จัดเรียงเป็นวงกลมรอบจุดศูนย์กลาง ต่อด้วยปลายแหลมรูปหมุด
   ดูโค้ด SVG อ้างอิงได้จากดีไซน์แคนวาส (artboard "แนวทางตราสัญลักษณ์") คัดลอกพิกัด SVG
   path ให้ตรงกับที่เห็นในมอคอัพ

3. เปลี่ยนไอคอน "เพื่อน AI" (AiSparkle ใน icons.tsx):
   gradient ปัจจุบัน (#4285F4 → #9B72CB → #D96570) เหมือนสัญลักษณ์ Gemini ของ Google เป๊ะ
   เปลี่ยนเป็น gradient ที่ผูกกับแบรนด์เอง: ม่วงแบรนด์ #7C3AED ไล่ไปสีเสาหลักที่กำลังพูดถึง
   ในบริบทนั้น (ทำให้ gradient เป็น prop ที่รับสีปลายทางได้ แทนที่จะ fix สีตายตัว)

4. เปลี่ยนลวดลายพื้นหลังหน้า marketing (globals.css → .jr-page-wash, และ

   "Landing" ในดีไซน์แคนวาส (คัดลอกแนวคิด ไม่ต้องคัดลอกพิกัดเป๊ะ เพราะต้อง responsive

5. อัปเดต favicon/app icon (src/app/icon.svg, src/app/apple-icon.png,

   ที่ขนาดจิ๋วในแท็บเบราว์เซอร์

6. แก้บั๊กเนื้อหาที่เจอระหว่างอ่านโค้ด (ไม่เกี่ยวกับรีแบรนด์ แต่เจอระหว่างทาง):

   ทั้งที่ราคาจริงใน lib/billing/plan.ts (PLAN.yearlyThb) คือ 299 — แก้ให้ใช้ตัวแปร {price}
   เหมือนคีย์อื่น ๆ ในไฟล์เดียวกัน เช็ค messages/en.json ด้วยว่ามีปัญหาเดียวกันไหม

7. (ทางเลือก แต่แนะนำ) ปรับค่าเริ่มต้นของ layout mode:
   ตอนนี้ default เป็น "mobile" ซึ่งครอบทุกหน้าจอไว้ในกรอบมือถือปลอมแม้บนเดสก์ท็อป
   (ดู globals.css บรรทัด data-layout="mobile" + @media min-width:512px) ส่งผลให้หน้า
   Vision Board ถูกบีบพื้นที่วาดเหลือน้อยมากบนจอกว้าง เสนอให้ default เป็น "desktop" เมื่อ
   viewport กว้างพอ แล้วให้ผู้ใช้เลือกโหมดมือถือเองถ้าอยากได้ฟีล gamified — ถามก่อนแก้เพราะ
   เป็นการเปลี่ยนพฤติกรรม UX หลักของทั้งแอป ไม่ใช่แค่เปลี่ยนแบรนด์

ทำทีละข้อ แสดง diff ให้ดูก่อนแล้วค่อยไปข้อถัดไป อย่าเปลี่ยนสี 6 เสาหลัก โครงสร้างการ์ด
(rounded-3xl/rounded-[2rem] + shadow-card) หรือฟอนต์ Prompt — สามอย่างนี้ยังใช้ได้ดีอยู่
ไม่ต้องแตะ
```

## หมายเหตุ

- ลิงก์ design canvas ให้แนบเองตอนวาง prompt (ระบบสร้างให้ในแชทที่ได้ไฟล์นี้มา ไม่ได้ฝังไว้ในไฟล์นี้เพราะลิงก์อาจเปลี่ยนถ้ามีการอัปเดตแคนวาสภายหลัง)
- ดีไซน์แคนวาสเป็นมอคอัพนิ่ง (ไม่ใช่ prototype กดได้) — ใช้เป็นข้อมูลอ้างอิงภาพและโค้ด SVG/สี ไม่ใช่โค้ดที่ copy-paste ได้ทั้งดุ้น เพราะโครงสร้างจริงของแอปเป็น React/Tailwind ต่างจาก markup ในแคนวาส
- ก่อนสั่ง Claude Code ทำจริง แนะนำให้เปิดดูดีไซน์แคนวาสก่อน ถ้าอยากปรับสี/เลย์เอาต์จุดไหนในมอคอัพ แก้ตรงนั้นก่อน แล้วค่อยเอา prompt นี้ไปสั่งให้ลงโค้ดจริง จะได้ไม่ต้องแก้ซ้ำสองรอบ
