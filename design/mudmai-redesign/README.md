# หมุดหมาย (Mudmai) — Redesign Package

โฟลเดอร์นี้รวมทุกอย่างจากการรีแบรนด์ Journey Resolution → หมุดหมาย (Mudmai):

1. **ทำไมไม่มีสกรีนช็อตของแอปจริง** — อธิบายไว้ด้านล่างในไฟล์นี้
2. `UX-AUDIT.md` — จุดที่ควรแก้ใน UI ปัจจุบัน อ่านจากซอร์สโค้ดจริงทั้งหมด (ไม่ใช่ความเห็นทั่วไป)
3. Design canvas (ลิงก์ในข้อความแชท) — มอคอัพหน้าจอที่ออกแบบใหม่จริง 4 ชิ้น: หน้า Landing, หน้าหลัก (มือถือ), หน้าราคา, และตัวเลือกตราสัญลักษณ์ 2 แนวทาง
4. `CLAUDE-CODE-PROMPT.md` — prompt พร้อมวางใน Claude Code เพื่อเอาดีไซน์ใหม่ไปใส่ในโค้ดจริงของโปรเจกต์

## ทำไมไม่ได้รันแอปแล้ว capture หน้าจอจริง

ลองแล้วจริง ๆ — ดึงซอร์สโค้ดทั้งโปรเจกต์ (177 ไฟล์ ไม่รวม `node_modules`/`.next`/`.git`) เข้ามาในนี้ ตั้งค่า demo mode (`JR_ALLOW_DEMO=true`) ตามที่ README ของโปรเจกต์บอกไว้แล้ว แต่ตอนจะ `npm install` เพื่อโหลด dependency (Next.js, Prisma, tldraw ฯลฯ) เจอว่าเซสชันนี้ไม่มีสิทธิ์ต่อเน็ตออกไปที่ npm registry เลย (ทุก request โดนปฏิเสธที่ระดับ network policy ขององค์กร ไม่ใช่ปัญหาที่โค้ด) และเซสชันนี้ก็ไม่มีสิทธิ์รันคำสั่งบนเครื่อง Mac ของคุณโดยตรงด้วย (มีแค่สิทธิ์อ่าน/เขียนไฟล์ผ่านโฟลเดอร์ที่เชื่อมไว้) เลยไม่มีทางรัน `npm run dev` ให้เกิดหน้าจอจริงขึ้นมาได้ในช่องทางนี้

ทางเลือกที่ทำแทนเพื่อให้ยังได้ของจริง ไม่ใช่แค่คำแนะนำลอย ๆ:

- **อ่านซอร์สโค้ดจริงทั้งหมด** (globals.css, ทุกหน้า, ทุก component หลัก) แล้วดึงค่าออกแบบจริง (สี, ฟอนต์, ขนาด, เงา, โครงสร้าง) มาทำ audit และมาออกแบบใหม่ — ไม่ได้เดาหรือจำจากแอปทั่วไป
- **สร้างมอคอัพจริง** ด้วย Claude Design จากค่าที่ดึงมา แทนสกรีนช็อต — เห็นภาพจริงว่าดีไซน์ใหม่หน้าตาเป็นยังไง

ถ้าอยากได้สกรีนช็อตของจอจริงเป๊ะ ๆ วิธีที่เร็วที่สุดคือรัน `npm run dev` เองบนเครื่อง แล้วส่งภาพมาให้ดู หรือถ้าอยากให้ช่วยรันจริงในเซสชันถัดไป บอกได้ว่าจะให้ลองทางไหน (เช่น เปิดสิทธิ์เน็ตให้เซสชันนี้ หรือรันคำสั่งบนเครื่องคุณเองแล้วส่งผลลัพธ์มา)
